How to make the token
  1. Go to github.com → Settings → Developer settings → Fine-grained tokens.
  2. Repository access: Only select repositories → Yordine-Salvador-Chimbutane.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Set an expiry you are comfortable with, generate it, and paste it above.

The token is held in this browser only (localStorage) and is sent nowhere but api.github.com. Anyone who can use this browser profile can use it, so on a shared machine leave the box unticked and use Sign out when you finish.
